# TiedChain Website

Static website prepared for deployment on Cloudflare Pages / Workers.

## Files
- `index.html`
- `style.css`
- `script.js`
- `favicon.svg`

## Deploy
Upload all files to the root of the GitHub repository `tiedchain-website`.
Cloudflare will redeploy automatically after the commit.

## Important
Replace `hello@tiedchain.com` when the business email is ready.
Replace the disabled demo button link when the Windows demo file is uploaded.
